# ------------------------------------------------------------
# CMDLINE 修正点（对照原 build.yml 第 355 行）:
#
# 1) root= 旧写法: /dev/block/mtd/by-name/rootfs
#    这是 Android 4.4 RK 老内核(NAND/mtd 框架)的节点；主线 6.12 + eMMC 上
#    根本不存在。改用 root=LABEL=rootfs（rootfs.img 已用 mkfs.ext4 -L rootfs
#    打标签，见 build.yml 打包步骤），不依赖分区编号。
#    若内核不支持 label 挂载，可改为 root=/dev/mmcblk0p4（p 号按 eMMC 实际
#    分区顺序：Loader/Parameter/boot/rootfs，通常 rootfs 是第 4 个分区）。
#
# 2) 删除 mtdparts=rk29xxnand:... ：主线内核无 rk29xxnand mtd 驱动，
#    该参数只会产生无效警告；eMMC 分区由内核 mmc 层识别。
#
# 3) 增加 rootwait：等 eMMC 枚举完成再挂根，避免启动早期块设备未就绪挂根失败。
#
# 4) console=ttyS0：必须与 DTS 使能的串口(&uart0)、README 三者一致。
#    若实测 TTL 接在 UART2，则 DTS 改 &uart2 status=okay、这里改 ttyS2、
#    README 同步，三处必须一致。
#
# 5) 删除 dwc_driver=2：Android 老 USB 参数，主线内核不识别。
# ------------------------------------------------------------
CMDLINE:console=ttyS0,115200 earlycon root=LABEL=rootfs rw rootwait rootfstype=ext4 init=/sbin/init maxcpus=1
