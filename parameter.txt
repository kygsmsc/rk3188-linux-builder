# ============================================================
# parameter.txt — RK3188 盒子 Linux（路线 A 修正版）
#
# 相对教程原版的修改：
#   [1] mmcblk0p1 → mmcblk1p1
#       本机 eMMC 是 mmcblk1（TTL 日志：mmcblk1: mmc1:0001 004GA1 3.69 GiB），
#       教程原版的 mmcblk0p1 在本机会挂根失败。
#   [2] 删除 initrd=0x62000000,0x00800000
#       无 initramfs，留着会报 "Initramfs unpacking failed: invalid magic"。
#   [3] 保留 mtdparts=rk29xxnand:...
#       loader 用它定义分区布局，RKDevTool "升级固件" 模式按它重写 eMMC MBR。
#   [4] 保留 dwc_driver=2
#       老 BSP USB 参数，6.12 忽略。
#
# 【刷机前必做】
#   擦除 eMMC 旧 MBR（原厂 Android 分区表残留会导致 mmcblk1p1 只有 2MiB）：
#     TTL 登录后执行：
#       dd if=/dev/zero of=/dev/mmcblk1 bs=1M count=1 conv=fsync && sync
#     然后 RKDevTool 用 "升级固件" 模式刷机（会自动重写 MBR）。
# ============================================================
CMDLINE:earlyprintk console=ttyS2,115200 root=/dev/mmcblk1p1 rootfstype=ext4 rw rootwait init=/sbin/init maxcpus=1 mtdparts=rk29xxnand:0x00008000@0x00002000(boot),-@0x0000A000(rootfs) dwc_driver=2
